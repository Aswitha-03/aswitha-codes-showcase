# Aswitha B — Developer Portfolio

## Goal
Build a polished, responsive dark portfolio that presents Aswitha as a credible early-career software developer, with projects as the strongest visual focus.

## What I’ll build
- A sticky desktop navigation and accessible mobile menu linking to each section.
- A professional opening section with Aswitha’s role, summary, calls to action, social placeholders, and a tailored developer-workspace image.
- About and education highlights with the supplied academic details.
- Grouped skills covering only the technologies and concepts provided.
- A prominent project showcase with all three projects, exact technologies, key features, and placeholder action links.
- Professional experience timeline, certification grid, and co-curricular activities.
- A contact section with the supplied email and phone number plus a clearly non-submitting, integration-ready contact form.
- A footer with the required copyright and social placeholders.

## Visual direction
- Deep charcoal surfaces with crisp cyan accents and restrained warm amber details.
- Editorial developer aesthetic: strong typography, subtle grid texture, fine borders, and selective glass effects.
- Smooth section entrances, gentle card movement, and reduced-motion support.
- Responsive layouts for mobile, tablet, and desktop without distracting effects.

## Technical details
- Build in the existing React and Tailwind application using reusable data-driven sections.
- Use semantic design tokens in the global design system and existing accessible controls.
- Keep all supplied external URLs as literal placeholders; the resume button will be visibly marked as pending connection.
- Add route-specific SEO metadata, semantic headings, accessible labels, and keyboard-friendly navigation.
- Validate the rendered page at desktop and mobile sizes, including the mobile menu and form behavior.
